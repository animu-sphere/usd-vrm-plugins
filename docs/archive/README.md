# Archive

> **Historical only.** Do not use archived documents to determine current
> architecture, capabilities, ownership or roadmap.

Plans and tracks that were once authoritative and no longer are: completed
migrations, superseded plans, retired proposals. They are kept for
traceability — reports, release records and sibling repositories cite their
section numbers — and they are not updated except to keep links resolving.

This is not [reports/](../reports/). A report is a dated measurement and stays
true of the day it was taken; an archived plan is intent that has either been
done or been replaced. Where a current document needs something an archived
one decided, the decision lives in the current document and the archive is
cited as its history.

Superseded design documents are not moved here. They stay at their path as a
short stub naming their replacement, so a citation of the old path still
leads somewhere: [MOTION_ARCHITECTURE_POLICY.md](../design/MOTION_ARCHITECTURE_POLICY.md)
and [MOTION_CONTRACT.md](../design/MOTION_CONTRACT.md).

The phase vocabularies these documents use — **Motion Phase A–H**, **MIG-0 to
MIG-5**, **BND-0 to BND-5**, the tracks' own milestone letters — are retired
with them, and appear only here, in the release records, and in reports.
