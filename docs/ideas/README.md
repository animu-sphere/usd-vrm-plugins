# Research and ideas

These are **research**, owned by `usd-vrm-plugins`, with no target version or
implementation commitment. Promote an idea to backlog only with a consumer,
next action, acceptance criterion and evidence destination. Prior plans are
preserved in the [documentation audit](../reports/2026-10-31-documentation-ownership-audit.md).

| Idea | Question / condition for promotion |
| --- | --- |
| Native USD export distribution profiles | Identify an actual consuming application, its package/metadata requirements and a reproducible validation path before promising an ARKit profile. |
| Optional `--keep-source` and package metadata | Establish a provenance consumer and retention contract; these do not imply reverse conversion to VRM. |
| VRM → USD → VRM | Feasibility only: reverse mapping, editable fields, unsupported edits and loss reporting. No VRM exporter has been committed. |
| VRMA export | Identify a recorded/baked clip consumer and expected loss before defining a writer. |
| Generic export helper extraction | A second workspace must need the same workflow before proposing an OpenStrata identity. |
| Morph overlap diagnostics | A geometry-analysis consumer must need reports about expressions displacing shared vertices; VRM 1.0 overrides already cover declared arbitration. |
| Optional ExecIr FK/switching/inverse | [Responsibility audit](../roadmap/execir-track.md#p0-1--execir-responsibility-audit-); subsequent steps depend on its result. |

## Canonical-model tooling

A stable debug dump or separate canonical validator needs a concrete importer
diagnostic use case; it is not justified by an uncommitted exporter alone.
The model stays private. Existing raw-source preservation and normalization
contracts remain in force; this idea does not remove them.

## Spring and world integration

SB-O3 (external/world colliders) waits for a consumer and the physics owner's
shared-collider/world-membership contract. Offline spring baking also waits
for an offline consumer. These do not reopen the completed solver track.
